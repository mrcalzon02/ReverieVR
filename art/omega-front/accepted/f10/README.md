# F10 — Farwake painted icon atlas

Twenty 256×256 square painted unit / support portraits, five columns by four rows in atlas_5x4.png. The first five roles are the proposed F10 dossier core; all other names are artwork concepts, not final game-canon commitments.

The game runtime portraits are under `app/src/main/assets/native/omega-front/ui/icons/f10/` with SHA-256 checksums and role mapping in its manifest. These are distinct from the 64px tactical map sprites and should be loaded only when a roster panel uses them.

# Omega Front — The Farwake (F10)

Twenty square 256×256 **source SVG concept tiles** in the original gold-framed Omega art direction. Distant-future human refugees, pearl/cyan armor, triangular drones, compact equipment and resource scarcity. The first five roles follow `docs/project/OMEGA_FRONT_FACTIONS.md`; the rest are proposed.

**Not yet committed:** locally generated PNG atlas and icon files. **Not integrated:** runtime UI lookup and APK. These SVGs are source-only alternatives, not the final painterly portraits.

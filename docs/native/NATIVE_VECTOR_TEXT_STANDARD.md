# Native game typography — genuine licensed font migration

**Status:** eight native Classics and four featured LatoLayer games have source-level licensed font rendering; current 15-game Android image recapture and Galaxy S9 visual acceptance tracked separately.

Functional in-game lettering must be glyphs from a real licensed font, not 3D symbol/segment meshes. `breakwater_font_atlas.h` contains the project's previously approved derived **Lato Semibold** antialiased alpha atlas, licensed under SIL OFL 1.1 (`LICENSES/OFL-1.1.txt`). The original glyph proportions, advances and punctuation are now used by Breakwater Battery and **all eight native Classics**; the six formerly unconverted Classic menus no longer call `classicart::StrokeText`. No font binaries are distributed separately.

## Shared native UI renderer (implemented; emulator retest pending)

`reverie_native_lato_text.h` provides `reverie::nativetext::LatoLayer` for modular GLES2 games: text strings become 8-float-per-vertex UV/color glyph quads using `font::AppendText` and `font::FittedScale`. Per-module font atlas is decoded/uploaded once at GL-context creation with Android's system `-lz`, one dynamic VBO for the current screen, and one draw per eye. Does not allocate shaders/textures during frames. Uses shader attribute slots 3, 4, 5 (to avoid games' 0/1 mesh and Gumball's 2 image attribute), alpha blending and full attribute plus prior program/buffer/texture/blend-function state restoration. Modules must call `Clear()` when rebuilding a menu, `Create()` at GL start, `Draw(mvp)` after their real game geometry, `Release()` at context release, and must fail initialization if font decoding is unavailable: **no fallback to fake glyph meshes**.

**Current source conversion:** all four requested modules have migrated independently to `LatoLayer`: **Ministry: Lantern Desk** and **Iron Sight: Forward Detachment** share `recon_projects_module.cpp`; **Omega Front** routes its sector map, small-sector labels and tactical HUD text to font quads after preserving the strategic/tactical terrain sprite draw order; **Gumball Armada** routes its chart, mission cards, shipyard, loadout, allies and HUD strings to font quads while retaining actual RGB565 route/ally artwork and the current click/hover rectangles. NDK targets for both recon modules and Gumball explicitly link Android's `-lz`; Omega already linked it. Each code change is a separate source commit. The [real Android 10 capture workflow #40380017382](https://github.com/mrcalzon02/ReverieVR/actions/runs/40380017382) subsequently completed **SUCCESS**, and its actual four initial/menu-frame PNGs were decoded and compared visually against baseline run 40286810374. All four initial screens have now demonstrated readable proportional font glyphs; this is **static Android emulator acceptance**, not S9 binocular/thermal/controller validation or proof of every secondary menu/gameplay HUD layout.

**Next acceptance:** the four actual initial/menu frames have been inspected: [raw capture ZIP](https://drive.google.com/file/d/1Jlm2t6vgEgCbplLr51P_9Tx1Z2WYRP7h/view), [before/after pixel comparison](https://drive.google.com/file/d/1gBEpdT5p35Zubp-c8_dMpY9COB9LkMpC/view). Check non-menu mission views subsequently. The legacy `reverie_native_vector_text.h` may remain as a library for decorative geometry, but **no registered Classic or previously migrated featured native game** may use `StrokeText` for player-facing labels. The original implementation's six remaining Classic text paths were converted to the same licensed Lato atlas on 2026-10-29, including static/dynamic VBO lifecycle, GL release and zlib linkage. `scripts/verify-native-vector-font.py` now rejects stroke-letter regression for these modules and verifies all eight Classic Android.mk targets include `-lz`.

## 2026-10-29 Classic font completion

All eight Classic game variants compile from `classic_games_module.cpp`; previously only Chess and Checkers built their native font programs and glyph vertex buffers. The font path now applies to every variant, including Pong, Snake, Go, Reversi, Breakout and Chutes & Ladders. The non-board games reset dynamic glyph batches per rebuild and upload a static glyph batch for their fixed title/instructions, rather than omitting static lettering or accumulating duplicates frame after frame. Rendering uses the pre-existing Lato atlas and alpha-quad pipeline; gameplay state, physics, hitboxes, save formats and input are unchanged. This is **source and CI build validation** until refreshed real emulator captures are inspected; hardware legibility is a separate gate.

## Red Ledger room labels and status plaques — 2026-10-29

`red_ledger_signage.h` now emits only physical backplate geometry and stockroom card rectangles. The old homegrown five-by-seven alphabet and raised box-pixel glyph emitters have been removed. `red_ledger_module.cpp` builds **genuine Lato atlas text** into its `uiFont` layer for the current room's static signage, each visible stockroom card label, and all six changing economic-information rows. The batch rebuilds only when the room or underlying game state marks the status dirty, not in both stereo-eye draws. The font is decoded once per GL-context lifetime, restored across context loss, and rendered after the physical room with the shared GL-state-preserving alpha-glyph shader. The Red Ledger module already links Android system zlib. The existing sign-layout test now asserts that no fake letter rectangles remain. Actual Android emulator menu/frame captures and S9 optics are distinct acceptance gates.

# Native stroke-text adoption — bounded source slice

**Source-only; updated 2026-10-17. Signed APK and device acceptance pending.**

The common `reverie_native_vector_text.h` renderer exposes connected-stroke `StrokeText` glyph paths from `classic_vector_art.h` through existing GLES2 XYZRGB flat-mesh triangles. This is not a font-file loader or a texture/shader dependency.

The connected-stroke layer remains used by **Omega Front**, **both reconnaissance previews**, **Gumball Armada**, and the *six* remaining non-Chess/non-Checkers native classics (Pong, Snake, Chutes & Ladders, Go, Breakout and Reversi). **Breakwater Battery, Classic Chess, and now Classic Checkers** render genuine proportional, antialiased Lato Semibold glyphs from the existing licensed `breakwater_font_atlas.h` (SIL OFL 1.1): one GLES2 alpha texture per game GL context, separate static/dynamic 8-float alpha-glyph quad batches, no font rasterization during stereo draw, and a GL-state restoration path. Chess still has its own chess-piece/wood atlas and chess-specific analysis side panels; the Checkers change is only menu/status/instructions and crowned-'K' lettering. The font alpha atlas is an existing offline source blob with bundled license, not a system-font runtime dependency. Red Ledger retains independent static signage.

**Migration status:** Checkers is the *first new* classic game converted in response to actual emulator-capture readability issues. Do not bulk-switch the other six classics until each screenshot is assessed and its fonts fit headings, HUD, status, controller focus/target labels and the VR projection. Gumball Armada, Omega Front and reconnaissance previews still need explicit conversion; preserve game-specific art/logos. The existing `scripts/verify-native-vector-font.py` checks older stroke-migration claims and is not a font-quality acceptance test. A dedicated Android 10 recovery/capture workflow now runs when `classic_games_module.cpp` changes, storing real before/after evidence; its completion must be checked before claiming Android success. S9 stereo optical legibility, contrast, thermal budgets and controller hitbox parity remain pending.

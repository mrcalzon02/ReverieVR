# Native game typography — genuine licensed font migration

**Status:** actively implemented in stages; actual Android/GLES2 and Galaxy S9 visual acceptance tracked separately.

Functional in-game lettering must be glyphs from a real licensed font, not 3D symbol/segment meshes. `breakwater_font_atlas.h` contains the project's previously approved derived **Lato Semibold** antialiased alpha atlas, licensed under SIL OFL 1.1 (`LICENSES/OFL-1.1.txt`). The original glyph proportions, advances and punctuation are used by Breakwater Battery and by Classic Chess and Classic Checkers. No font binaries are distributed separately.

## Shared native UI renderer (implemented; emulator retest pending)

`reverie_native_lato_text.h` provides `reverie::nativetext::LatoLayer` for modular GLES2 games: text strings become 8-float-per-vertex UV/color glyph quads using `font::AppendText` and `font::FittedScale`. Per-module font atlas is decoded/uploaded once at GL-context creation with Android's system `-lz`, one dynamic VBO for the current screen, and one draw per eye. Does not allocate shaders/textures during frames. Uses shader attribute slots 3, 4, 5 (to avoid games' 0/1 mesh and Gumball's 2 image attribute), alpha blending and full attribute plus prior program/buffer/texture/blend-function state restoration. Modules must call `Clear()` when rebuilding a menu, `Create()` at GL start, `Draw(mvp)` after their real game geometry, `Release()` at context release, and must fail initialization if font decoding is unavailable: **no fallback to fake glyph meshes**.

**Current source conversion:** all four requested modules have migrated independently to `LatoLayer`: **Ministry: Lantern Desk** and **Iron Sight: Forward Detachment** share `recon_projects_module.cpp`; **Omega Front** routes its sector map, small-sector labels and tactical HUD text to font quads after preserving the strategic/tactical terrain sprite draw order; **Gumball Armada** routes its chart, mission cards, shipyard, loadout, allies and HUD strings to font quads while retaining actual RGB565 route/ally artwork and the current click/hover rectangles. NDK targets for both recon modules and Gumball explicitly link Android's `-lz`; Omega already linked it. Each code change is a separate source commit. The [real Android 10 capture workflow #40380017382](https://github.com/mrcalzon02/ReverieVR/actions/runs/40380017382) subsequently completed **SUCCESS**, and its actual four initial/menu-frame PNGs were decoded and compared visually against baseline run 40286810374. All four initial screens have now demonstrated readable proportional font glyphs; this is **static Android emulator acceptance**, not S9 binocular/thermal/controller validation or proof of every secondary menu/gameplay HUD layout.

# Gumball Armada — ReverieVR Native Game

**Status:** design and initial implementation underway; no APK/device acceptance.

An original confectionary-space arcade shooter and ship-builder. The missing Candy King is sought by a commander commissioned by the Gubernatorial Gumball. Enemies are the Sour Armada led by Sally Scrunch, Captain Cringe, Pete Pucker and Senator Sauer.

Gameplay: branching deterministic transit-lane map, flight combat with held touchpad directional steering and click-to-fire, kill-combo multiplier, Gumball cash economy, modular hull/blaster/thruster/shield improvements, commander rank, four fortified command regions. The long-term plan includes salvage/stealing/trading components, boarding, major capital warships, voice-announcer callouts, a broad interstellar lane network and original soundtrack. Keep actual shipped features separate from these future objectives.

Use original designs, art, sound and terminology rather than copying copyrighted Kingdom Hearts or Candy Crush assets. Target Galaxy S9 and Daydream in the existing single APK. Do not register a user-visible menu item until native gameplay and the Daydream input binding actually work.

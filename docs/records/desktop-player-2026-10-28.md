## Playable desktop Home foundation — October 28, 2026

`tools/desktop/player/` is a separate headset-free Java17 Swing Home application, not the scene editor and not a feature-complete platform port. It reads the same canonical registry/environments without copying game identities. A forward-facing wall projection hosts the Native Games menu, while room movement, keyboard input, environment, avatar color and Quick Menu continue outside the gallery. The three **actual desktop-playable** classic IDs are Pong, Snake and Breakout. All 15 registered module IDs remain visible in the canonical source; 12 are deliberately not represented as runnable desktop games. The Android `libreverie_module_*.so` ABI has not been ported to Windows/macOS/Linux by this Java step.

`tools/desktop/player/test.sh` runs source-accurate headless state/graphics/arcade tests. A graphical desktop smoke requires a working display server on Linux or an interactive Windows/macOS test session; it does not prove all inputs, visual comfort or installability. This executable-in-a-window prototype must not be advertised as full native Windows/Linux/macOS delivery. It does not add an Actions workflow.

**Next substantive gate:** native platform window/graphics/input adapter with an actual portable classic module host, reuse of the authored REVSCENE bridge and eventual real Home meshes. After that, game ABI/GL/audio/save/service adapters with per-title launch verification, DOS and media, gamepad, whole-app packaging and optional OpenXR. Keep Home windows in the Home room; entering a game is a deliberate gameplay transition.

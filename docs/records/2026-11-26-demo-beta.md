# November 26, 2026 demo beta

## Scope and source

Owner-authorized demonstration release of the unified Daydream/ReverieVR APK.
Starting `main`: `532f128a291906c5a40a1d1bb3d48ce5fe7b6f44`.
Previous published phone beta: `phone-test-2031-1`, source
`ed33356203fd9b6967169b43b4986de489d350eb`, published November 17 UTC.
There are 146 intervening commits, including validation and genuine screenshot
archives as well as game changes. The current candidate preserves that work.

This pass is limited to launch, playability, usability and update delivery.
No engine, render-loop, simulation-rate, performance or architectural refactor
is part of this demo repair. The permanent distribution signer is preserved.

## Repairs in this release pass

- The phone's Bundled Game Library now says **Included (early access)** instead
  of incorrectly requiring Development logging to launch bundled games.
- Android 13+ receives download-completion broadcasts from the platform Downloads
  provider. The active download ID, trusted URL, APK digest, package ID, newer
  Android version and persistent signer checks remain mandatory.
- An explicit phone-test release marker now also starts the existing installed
  hub, Android recovery/capture and all-game functional workflows. No duplicate
  workflow or new visual/style release gate is introduced.
- Native admission documentation now describes current bundled-game behavior.

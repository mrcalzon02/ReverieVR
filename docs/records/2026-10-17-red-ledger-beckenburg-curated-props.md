# Red Ledger — selective Beckenburg asset reuse (2026-10-17)
ReverieVR main-only integration; game module: `between-deliveries-red-ledger`.

Only five source GLBs were selected from the Beckenburg Drive master library: `light_switch_1.glb`, `ceiling_lamp_1_off.glb`, `door_1_loose.glb`, `shelf_mp_6.glb`, and `chair_mp_5.glb`. The source index lives at https://docs.google.com/document/d/18G144Qd0-L5rL7NdqxMykqkXaBHtu8-ytr_yYPol6rI/edit . Their exact original Drive file IDs, respectively, are `1NjpBld90_JZu6D3rBKeNIUpVWIWpNCbU`, `1QCYJxy6Y304tEnvyCUaIhgU5u_MgyegB`, `15iG_N9Im5QAmWAFqS20I7K6f83tk4QBc`, `10oe2_da014wJf9_tm3YdEIjpFSAmHezf`, `1h0jLPo08n44TyKMAhgfiM8A50aFYQ8zf`.

Actual source GLB meshes (not thumbnail substitutes) have been locally inspected and converted into `RLBP` v1 files with preserved indexed triangle faces, transforms, material textures, UV coordinates and per-material color. Output packages use an RGB565 256×256 baked material texture and interleaved aligned GLES2 attributes. A bounded decoder validates header, dimensions, triangle count, float finiteness and payload length; native loading/upload occurs at GL-context creation, and bar/stockroom/living-room placement uses the existing draw shader. Invalid or missing optional props do not prevent the Red Ledger bar from launching; loading diagnostics report the exact accepted count.

**Public-repository licensing boundary:** The owner purchased the PSX Mega Pack for commercial game use. Commercial game use does not prove that publishing raw pack assets or reconstructable mesh derivatives in a public GitHub source tree is permitted. This change intentionally contains **no proprietary GLB, extracted texture or RLBP** in the public repository. The five converted `.rlprop` files are individually prepared in private local staging and must be placed in `app/src/main/assets/native/red-ledger/beckenburg/` only in an authorized distributable package after the pack's EULA is confirmed. The unmodified source ZIP and complete library remain in Beckenburg Drive.

Source integration is **not** APK acceptance: no Android/NDK build, Galaxy S9 GLES2 screenshot, controls or thermal acceptance was performed for these props. Existing original product FBX models, shop icons, sounds and inventory remain authoritative and unchanged. No GitHub Actions.

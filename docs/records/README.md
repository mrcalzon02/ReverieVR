# ReverieVR Architecture and Decision Records

This directory stores durable decisions, investigations, compatibility findings, provenance records, and architecture rationale.

Use records when a decision would otherwise be repeatedly rediscovered or silently drift.

A decision record should include:

- problem/context;
- decision;
- alternatives considered;
- evidence;
- consequences/tradeoffs;
- validation implications;
- date/status;
- affected backlog targets.

Do not use this directory as a second backlog or execution ledger.

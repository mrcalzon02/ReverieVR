# Breakwater authored texture expansion — 2026-11-04

Objective: commit *every* image-generated Breakwater material from the current project and make each a visible, functional material on real native 3D defense geometry, while preserving 60-Hz mobile VR design and encouraging selective cross-project reuse. This is art-only source integration, not a new game and not an unsubstantiated Android/device success claim.

**Existing**: six owner-generated 64×64 tiles already tracked by immutable Git blobs: shingle, quay concrete, basalt, oxidized steel, sandbags, olive enamel. Existing shore UVs and emplacement cladding were live in the native module prior to this pass.

**New**: ten user-generated textures from the subsequent image generation turns, converted with Pillow/LANCZOS into 64×64 paletted 64-color PNGs: dock_planks, mossy_seawall, corrugated_roof, camo_netting, diamond_plate, trench_soil, reinforced_concrete, crate_planks, riveted_bulkhead, pebble_ground. The ten independent resulting Git blobs were individually created through Drive raw bytes and matched the local Git SHA exactly. Total 33,396 bytes before packaging; all full-resolution originals remain outside the APK and the 64×64 optimized source files are also retained in the owner's Drive folder (https://drive.google.com/drive/folders/1Z_vqO-jRM6KVkEXkqpEAlnmPRhwi51fO). No raw full-resolution textures are copied into the distributable game.

**Actual native integration**: extend `materials::Surface` and `authored::kPaths` to 16 materials; maintain per-file CRC/PNG signature/opaque-64px guards; update procedural fallback, UV atlas height to 768 (128×768×4 = 393,216 bytes), and retain one texture/draw batch. 3D emplacement cladding now places new textures on the gun apron, bunker cheeks, sidewall roofs, shore-facing masonry, ammunition crates, camouflaged tarp, pillbox roofs and rear bunker access; the existing 24×20 height-meshed shore selects trench soil, wood planks and pebbles in appropriate map sections. Every new tile is referenced by at least one real location geometry path. Gameplay, physics collision, AI, orders, score, HUD and input intentionally unchanged.

**Shared use**: add 10 PNG blobs to `native/shared/v1/materials/coastal/`, update C++/Java exact allowlists, the immutable Git/SHA256 catalog and test companion staging. Existing six PNG blobs and three BWM1 blobs are retained byte-for-byte. Omega Front's active use of two existing common textures is unchanged; ten new tiles are allowed for future game consumers but not falsely reported as active in their rendering.

**Testing gates**: the exact Git-derived PNG output bytes were SHA validated against source on transfer, all ten 64×64 paletted. The new host regression now checks 16 tile CRC decodes/atlas slot copies, deterministic fallback, UV bounds/material samples and terrain selections; existing emplacement tests include new material-covered supplies/roofs. A passing host run, NDK APK, installed GLES2 screenshot and S9 two-eye performance MUST be established separately before marking actual device acceptance. Start-up texture loading/atlas height increases memory ~160 KiB over the old 128×448 material atlas; this remains bounded but needs headset thermal measurement.

Full-resolution reference archives are preserved in Drive: initial six: https://drive.google.com/file/d/1VCIZ2ub3eR4b0Zj-XngMjG81Kerf6U38/view ; additional ten: https://drive.google.com/file/d/1UkCZBniSCIQPC701YeH0U4yTqXP2xlzu/view . The committed APK includes only 64×64 derivatives.

## CI integration repair (same date)

A real GitHub Actions run for the 16-material source commit found two **test expectation** failures, not demonstrated render failures: the Breakwater campaign test asserted the historic 128 KiB sprite atlas size in three places, despite the deliberately expanded 128×768 RGBA single atlas, and the Omega Front CC0 verifier counted only 119 game-private PNG paths while ignoring its two shared baseline tiles. This correction makes the combat test use `kSpriteAtlasWidth*kSpriteAtlasHeight*4` and verifies exactly 119 distinct Omega-private + the two approved shared 64×64 source paths = 121 runtime slots, retaining 64 independently SHA-tested CC0 sprites. The full Android/NDK and headset tests remain separate acceptance gates.

# ReverieVR Daydream controller visual

Runtime asset: `vr_controller_daydream.obj`

This visual comes from **TechnoBuddhist/VR-Controller-Daydream**, a low-poly
Daydream controller model derived from **rje's "Daydream Vr Controller"**
Sketchfab model (model ID `c1944c64e06544babc90e9d0aa953551`).

The upstream README states that the derivative was created from rje's
CC-Attribution model, may be used with the README retained, and requires
attribution to rje. ReverieVR therefore preserves the upstream README beside
the asset and also preserves the upstream repository GPL-3.0 license file.

Sources:

- Original model by rje:
  https://sketchfab.com/3d-models/daydream-vr-controller-c1944c64e06544babc90e9d0aa953551
- Derivative model:
  https://github.com/TechnoBuddhist/VR-Controller-Daydream

The model geometry is used only for the controller visual. ReverieVR's input,
pose, raycast, button-state, and recovery logic remain independently authored.
